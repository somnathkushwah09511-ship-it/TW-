# Google Docs for Technical Writing & Collaboration

> **Key Idea**: Use Google Docs when you need speed, simultaneous teamwork, clean feedback loops, and polished formatted deliverables without local setup.

---

## 1. Quick Setup & Shortcuts

| Action | Shortcut (Windows) | Why it matters |
|---|---|---|
| **Add Comment** | `Ctrl + Alt + M` | Pin feedback to exact words |
| **Heading 1 / 2 / 3** | `Ctrl + Alt + 1 / 2 / 3` | Builds automatic outline & TOC |
| **Normal Text** | `Ctrl + Alt + 0` | Reset styles cleanly |
| **Footnote** | `Ctrl + Alt + F` | Academic/technical references |
| **Find & Replace** | `Ctrl + H` | Batch term corrections |

---

## 2. Review Modes: The Golden Rule

Google Docs has 3 editing states (top-right pen icon):
- **Editing**: Direct changes without markers. (Good for solo drafting)
- **Suggesting (Track Changes)**: Edits appear colored in margin. The document owner can click **✔ (Accept)** or **✖ (Reject)**. (Crucial for reviews)
- **Viewing**: Read-only mode to prevent accidental typos.

---

## 3. Real-Time Collaboration & Feedback Loops

1. **Tagging Teammates**: Type `@name` or `+email` inside a comment to notify them and assign task ownership.
2. **Version History (`Ctrl + Alt + Shift + H` or File → Version history)**:
   - Google Docs auto-saves every keystroke to cloud.
   - **Pro Tip**: Use *File → Version history → Name current version* at milestones (e.g., `Draft_Submitted_v1`).

---

## 4. Structuring Technical Documents

- **Automatic Table of Contents**:
  - Apply **Heading 1**, **Heading 2**, etc.
  - Go to `Insert → Table of contents`. It creates linked, auto-updating navigation.
- **Tables**: `Insert → Table` to organize data, comparisons, test results, or timelines.
- **Equations**: `Insert → Equation` (supports familiar LaTeX notation like `\alpha`, `\frac`, `\sqrt`).
- **Diagrams**: `Insert → Drawing → New` for flowcharts, or integrate add-ons (Lucidchart, Diagrams.net).
- **Citations**: `Tools → Citations` (supports APA, MLA, Chicago and in-text bibliography).

---

## 5. Exporting

- `File → Download → PDF Document (.pdf)` for final submissions.
- `File → Download → Microsoft Word (.docx)` for offline enterprise exchange.
- `File → Share → Publish to web` for instant read-only public sharing.
